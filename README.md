# Zetra Market Expansion Toolkit

![Zetra Company](https://via.placeholder.com/150x50?text=ZETRA)

## What is this?

The Zetra Market Expansion Toolkit is an interactive dashboard that helps our business strategists identify and evaluate new B2B market opportunities for 2025 growth plans. The application features a unique retro gaming aesthetic that makes complex data analysis both engaging and intuitive.

## What does it do?

This tool helps Zetra Company (Paris HQ) make smart decisions about where to expand our business by:

1. **Visualizing Market Research**: See industry trends, PESTLE analysis factors, and 2025 market dynamics in easy-to-understand charts
   
2. **Exploring Market Segments**: Filter potential B2B segments based on company size, region, growth rates, and other critical metrics
   
3. **Evaluating Opportunities**: Score and rank market segments using customizable weights for factors like market size, profitability, and AI readiness
   
4. **Building Entry Strategies**: Create and visualize implementation plans for target segments with timelines and ROI projections

## How does it work?

The application is organized into four main sections:

1. **Market Overview**: This dashboard shows the big picture of industries and external factors. Users can toggle between industry data and PESTLE analysis views.

2. **Segment Explorer**: This interactive tool lets users filter and discover potential market segments using customizable criteria.

3. **Evaluation Tool**: Users input segment data and assign different weights to evaluation factors. The tool calculates scores and displays factor-by-factor breakdowns.

4. **Target Strategy**: Once segments are selected, this module helps create market entry strategies with implementation timelines and financial projections.

## Why is this useful?

This toolkit provides several key benefits to Zetra Company:

- **Data-Driven Decisions**: Replaces gut feelings with objective analysis based on multiple criteria
  
- **Time Efficiency**: Condenses weeks of market research analysis into interactive sessions
  
- **Collaboration**: Creates a common visual language for strategy discussions across departments
  
- **Scenario Testing**: Quickly test different prioritization approaches by adjusting evaluation weights
  
- **Presentation-Ready**: Generates visually appealing charts and summaries for executive presentations

## Getting Started

### Installation

```
# Clone the repository
git clone https://github.com/zetra/market-expansion-toolkit.git

# Navigate to the project directory
cd zetra-market-expansion-toolkit

# Install dependencies
pip install -r requirements.txt

# Run the application
streamlit run app.py
```

### Using the Toolkit

1. Start with the **Market Overview** to understand industry landscapes and trends
2. Move to the **Segment Explorer** to discover potential market segments
3. Use the **Evaluation Tool** to score promising segments
4. Develop strategies for top segments in the **Target Strategy** module
